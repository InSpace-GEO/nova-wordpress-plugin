=== NOVA WordPress Plugin ===
Stable tag: 1.0.0
Requires at least: 6.9
Requires PHP: 8.0
License: Proprietary

Map existing layouts and publish NOVA deliveries to WordPress. Includes optional NOVA Blog, NOVA Service Pages and WooCommerce category rich text.

== Installation ==
Upload the nova-wordpress-plugin-1.0.0.zip release asset in WordPress. Deactivate NOVA Bridge Suite before activating the new plugin. Open Settings > NOVA Settings to configure layouts, the connection and optional modules.
